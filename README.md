# AMSA Vessel Traffic

Single-page web app (ArcGIS Maps SDK for JavaScript 4.31) that queries public ArcGIS Online feature layers built from AMSA AIS data (traffic density, going dark, impossible jumps, off-route, change detection, ship tracks, major ports).

Live page: https://mehdipira.github.io/amsa-vessel-traffic/

Data: AMSA digital data (AIS); ports from National Major Ports, AODN / CSIRO BECRC (CC BY 4.0).
